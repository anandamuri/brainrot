# **Brainrot Overlay**

- Keep Subway Surfers, Temple Run, or any video running while working, browsing, or studying.  
- Stay entertained while being productive.  
- Reduces boredom, cognitive load, and restlessness.
- Made this as a joke, so don't believe the benefits.

## Language
- **JavaScript**  
  - Manages drag-to-move, resize logic, triple-click detection, corner snapping, and DOM manipulation.

## Features

- **Triple Click to Toggle Visibility**  
  Quickly hide or reveal the overlay with a rapid triple-click anywhere on the widget.

- **Close Button (X)**  
  Instantly hide the widget by clicking the close button.

- **Resizable Window**  
  Drag the edges to resize the video overlay to your liking.

- **Snap to Corners**  
  Overlay automatically snaps to the nearest screen corner after dragging.

- **Autoload on New Pages**  
  Automatically opens when visiting new sites (when enabled via extension or script settings).
